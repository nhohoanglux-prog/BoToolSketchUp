# BoToolSketchUp

Bộ plugin SketchUp của Phúc. Mỗi plugin một thư mục, cài bằng file `.rbz` trong thư mục đó (SketchUp > Extensions > Extension Manager > Install Extension), sau đó tự cập nhật từ kho này.

- `MatBangXien/`: Mặt bằng xiên (plan oblique) – xem `MatBangXien/HuongDan.txt`.

Tool Photoshop nằm ở kho riêng: nhohoanglux-prog/BoToolPhotoshop.
