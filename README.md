# BoToolSketchUp

Bộ Tool SketchUp của Phúc: một bảng tool (giống Tool Launcher của bộ Photoshop) có ô tìm kiếm, chia nhóm, bấm là chạy, tự cập nhật từ kho này.

- Cài: tải `BoToolSketchUp.rbz`, SketchUp > Extensions > Extension Manager > Install Extension. Xem `HuongDan.txt`.
- Mã nguồn: `MaNguon/` (đúng cấu trúc thư mục Plugins của SketchUp). Mỗi tool một thư mục `MaNguon/phuc_botool/tools/<Id>/`.

Tool hiện có: Mặt bằng xiên (plan oblique / axonometric).

Tool Photoshop nằm ở kho riêng: nhohoanglux-prog/BoToolPhotoshop.
